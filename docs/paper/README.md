# Paper draft

MNRAS-style draft of the colour-only lensed-SN-Ia trigger results.

- `paper.tex` — the manuscript (targets `mnras.cls`).
- `references.bib` — bibliography.
- `figures/` — all figures (PNG), generated by the analysis scripts.

## Compiling

`mnras.cls` is **built into Overleaf** — the easiest route is to upload this
folder to a new Overleaf project and compile. Locally you need a TeX distribution
with the MNRAS class (download `mnras.cls` from the MNRAS author area into this
folder if it is not on your `TEXINPUTS`), then:

```
pdflatex paper
bibtex paper
pdflatex paper
pdflatex paper
```

If `newtxtext`/`newtxmath` are unavailable, delete that `\usepackage` line in the
preamble (the class supplies default fonts).
